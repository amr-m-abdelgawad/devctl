# Contributing to this repository

This file is for work **in the devctl repo**. To *use* devctl in some other project, see [Quick start](docs/quickstart.md) and [Developer setup](docs/developer-setup.md).

## Day-to-day

Runtime is [Bun](https://bun.sh) 1.4.0 or later. The loop is in [Building from source](docs/typescript.md):

```bash
export PATH="$HOME/.bun/bin:$PATH"
cd app
bun install
bun run src/bin.ts --help
bun test
bunx tsc --noEmit
```

Install the `devctl` command onto your PATH with `cd app && bun link`.

## Docs

User-facing pages live in [`docs/`](docs/README.md) and are published to the [GitHub Wiki](https://github.com/amr-m-abdelgawad/devctl/wiki) from `main`. Edit the files in `docs/`; do not edit the wiki in place. The wiki sidebar is generated by [`.github/scripts/prepare-wiki.sh`](.github/scripts/prepare-wiki.sh).

Agent onboarding instructions live in [`skills/`](skills/README.md). Keep `SKILL.md` as the single source of truth. This checkout already points at that skill from [`AGENTS.md`](AGENTS.md) and [`.cursor/rules/devctl-onboard.mdc`](.cursor/rules/devctl-onboard.mdc).

## Security

Report vulnerabilities privately. See [SECURITY.md](SECURITY.md). Product guarantees (loopback, redaction, no SA keys) are in [docs/security.md](docs/security.md).

## Releases

Maintainers: [npm publishing](docs/npm-publishing.md). Version lives in both `app/package.json` and `app/src/version.ts`.
